# Test Levels and Scope
**Document ID:** TEST-002 | Version 1.0

## Unit
Target:
- authorization
- policy engine
- spend limits
- state machines
- validators
- parsers
- Meta error mapping
- report calculations

## Integration
Target:
- database
- queues
- auth
- AI orchestration
- Meta adapter
- object authorization

## Contract
Validate OpenAPI schemas and provider adapter contracts.

## E2E
Validate critical user journeys from browser through backend and mocked/sandboxed external integrations.

## Manual
Human validation of UX, AI usefulness, approval safety and real Meta connectivity where appropriate.
