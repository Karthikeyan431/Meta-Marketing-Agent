# E2E and User Acceptance Testing
**Document ID:** TEST-007 | Version 1.0

## Critical Journey
1. Sign in.
2. Connect Meta.
3. Select an ad account.
4. Wait for initial sync.
5. View campaigns.
6. Use global search.
7. Ask AI for performance analysis.
8. Request a campaign change.
9. Review action preview.
10. Approve.
11. Execute.
12. Verify against provider state.
13. View audit history.
14. Generate a report.

## UAT Questions
- Is the AI understandable?
- Are recommendations grounded in visible data?
- Is the user always aware when a mutation is about to happen?
- Are approval details sufficient?
- Are errors actionable?
- Is navigation predictable?
- Does the product save meaningful manual work?
