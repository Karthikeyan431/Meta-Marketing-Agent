# Performance and Load Testing
**Document ID:** TEST-008 | Version 1.0

## Measure
- API latency
- page load
- search latency
- chat first-token latency where applicable
- AI completion latency
- database latency
- queue latency
- Meta adapter latency
- report generation time

## Load Scenarios
- concurrent users
- concurrent chat requests
- large campaign lists
- large Insights queries
- bulk action requests
- webhook bursts
- scheduled sync bursts

## Rule
Performance thresholds must be finalized from measured product requirements before production.
