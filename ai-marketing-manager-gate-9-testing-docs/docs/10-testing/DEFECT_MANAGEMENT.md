# Defect Management
**Document ID:** TEST-012 | Version 1.0

## Severity
- Critical: security breach, unauthorized spend, cross-tenant exposure, data corruption.
- High: major feature failure or serious security/control weakness.
- Medium: material degraded behavior with workaround.
- Low: minor defect.

## Rules
Critical defects block release.
High defects require explicit risk acceptance by an authorized owner.
Every production defect gets a root-cause classification where appropriate.
