# Definition of Done
**Document ID:** GOV-004  
**Version:** 1.0  
**Status:** Draft for Approval

A task/feature is complete only when all applicable items are satisfied.

## Requirements
- [ ] Requirement ID identified
- [ ] Acceptance criteria identified
- [ ] Relevant architecture reviewed
- [ ] Implementation completed
- [ ] Edge cases handled
- [ ] Error handling implemented
- [ ] Authorization verified
- [ ] Security implications reviewed

## Testing
- [ ] Unit tests pass
- [ ] Integration tests pass where applicable
- [ ] E2E tests pass where applicable
- [ ] Negative/security tests pass where applicable
- [ ] AI evaluation cases pass where applicable
- [ ] Manual verification completed where required

## Engineering
- [ ] Type checking passes
- [ ] Lint/format checks pass
- [ ] No unexpected regressions
- [ ] Database migrations verified
- [ ] Logging/observability added where required
- [ ] Retry/idempotency behavior verified for external operations

## Documentation
- [ ] Relevant documentation updated
- [ ] ADR added if an architectural decision changed
- [ ] API contract updated if applicable
- [ ] Test evidence recorded

## Release
- [ ] Git diff reviewed
- [ ] Known limitations recorded
- [ ] No secrets or sensitive values committed
- [ ] CI checks pass
- [ ] Deployment impact understood
