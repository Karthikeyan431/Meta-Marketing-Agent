# ADR-006 — Cloud
**Status:** Proposed

Initial production target: AWS.

Target capabilities:
- ECS/Fargate
- RDS PostgreSQL
- ElastiCache Redis
- S3
- Secrets Manager
- CloudWatch/OpenTelemetry-compatible observability
- Application Load Balancer
- WAF
- managed DNS
- Terraform

Infrastructure must remain modular and reproducible.
