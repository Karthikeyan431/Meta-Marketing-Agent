# Claude Code Verification Prompt

Review the implementation as a senior production engineer.

Check:
- requirements
- architecture
- security
- tenant isolation
- authorization
- API contracts
- database integrity
- Meta integration boundaries
- AI tool safety
- idempotency
- auditability
- error handling
- tests
- observability
- deployment readiness

Run available automated checks.

Then produce:
1. PASS findings
2. FAIL findings
3. Security risks
4. Correctness risks
5. Missing tests
6. Technical debt
7. Release blockers
8. Recommended fixes

Do not modify code during this verification pass unless explicitly instructed.
