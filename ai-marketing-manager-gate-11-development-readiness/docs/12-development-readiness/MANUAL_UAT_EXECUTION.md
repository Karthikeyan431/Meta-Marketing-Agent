# Manual UAT Execution Plan

## Preconditions
- staging environment available
- test Meta account/ad account available
- test user roles configured
- test data synchronized
- test spend controls configured safely

## Test
1. Sign in.
2. Connect Meta.
3. Select ad account.
4. Verify dashboard.
5. Search for an account/campaign with Ctrl/Cmd+K.
6. Ask a read-only AI question.
7. Validate evidence.
8. Ask for a controlled campaign change.
9. Inspect action preview.
10. Reject one action.
11. Create another and approve.
12. Verify provider state.
13. Inspect audit trail.
14. Generate report.
15. Trigger/simulate a provider failure.
16. Confirm truthful failure state.
17. Test unauthorized access with a second workspace/user.

Record screenshots and expected/actual results.
