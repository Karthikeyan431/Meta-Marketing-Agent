# Product-Level Acceptance Criteria
**Document ID:** DEVREADY-008 | Version 1.0

## Connection
User can connect Meta through the approved OAuth flow, select ad accounts, and see connection health.

## Data
User can view synchronized accounts/campaigns/ad sets/ads with correct workspace scope and freshness.

## Search
Ctrl/Cmd+K can resolve and navigate to the correct entity category without cross-tenant leakage.

## AI Read
User can ask natural-language performance questions and receive data-grounded answers.

## AI Action
User can request a mutation, review an exact preview, satisfy approval policy, execute, verify and inspect audit history.

## Safety
Unauthorized, ambiguous, replayed, injected or policy-violating actions are blocked safely.

## Reporting
User can generate a report with transparent source metrics, calculations, AI interpretation and freshness.

## Operations
Failures are observable, recoverable and truthfully represented to users.
