# Secure Coding Rules
**Document ID:** DEVREADY-010 | Version 1.0

- Parameterize database queries.
- Validate and constrain input.
- Encode output appropriately.
- Avoid dynamic code execution.
- Use secure session handling.
- Verify authorization at resource level.
- Protect against IDOR/BOLA.
- Protect against CSRF where applicable.
- Protect webhook endpoints.
- Apply rate limits.
- Avoid sensitive logging.
- Pin/scan dependencies.
- Use secure headers.
- Handle provider errors without leaking internals.
- Treat user-generated Meta content as untrusted input.
- Treat AI output as untrusted until validated by application code.
