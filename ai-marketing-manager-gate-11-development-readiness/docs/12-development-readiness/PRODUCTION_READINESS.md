- [ ] secrets protected

- [ ] monitoring active
- [ ] alerts routed
- [ ] backups active

- [ ] rollback tested

- [ ] staging UAT signed off
- [ ] production smoke plan ready
- [ ] controlled mutation rollout plan approved
- [ ] owner/on-call assigned
