# Repository-First Development Workflow
**Document ID:** DEVREADY-003 | Version 1.0

Claude Code must begin by understanding the actual repository.

## Required Assessment
Return:
- framework/runtime
- package manager
- existing applications
- backend/frontend boundaries
- database
- authentication
- existing integrations
- test framework
- build commands
- deployment configuration
- environment variables
- existing technical debt
- risks

## Required Artifacts
Create or update:
- `docs/implementation/repository-assessment.md`
- `docs/implementation/implementation-plan.md`

Never assume a greenfield repository unless inspection proves it.
