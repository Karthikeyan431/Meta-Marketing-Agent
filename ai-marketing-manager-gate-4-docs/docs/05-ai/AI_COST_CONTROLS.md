# AI Cost Controls
**Document ID:** AI-012 | **Version:** 1.0

## Controls
- per-user request limits
- workspace quotas
- token budgets
- maximum tool iterations
- maximum execution duration
- caching where safe
- model routing
- report generation limits

## Cost Attribution
Track usage by:
- workspace
- user
- AI run
- model
- operation type

## Abuse Prevention
Suspicious repeated or automated activity should be rate-limited without affecting critical safety controls.
