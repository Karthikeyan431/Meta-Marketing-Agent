# Requirements Glossary
**Document ID:** REQ-006 | **Version:** 1.0

**Workspace:** Tenant boundary containing users, configuration, integrations and data.

**Meta Connection:** Authorized connection between a workspace and Meta resources.

**Asset:** A Meta resource available to the connected business/ad account.

**Mutation:** An operation that changes external or platform state.

**Policy:** Deterministic rule determining whether an action is allowed.

**Approval:** Explicit authorization required before a configured action executes.

**Autonomous Action:** System-initiated action executed without a per-action user confirmation, within configured boundaries.

**Goal:** Measurable desired business/advertising outcome.

**Optimization:** Decision process intended to improve goal performance.

**Audit Event:** Durable record of a security, governance, or execution event.

**Data Freshness:** How recently synchronized data reflects the external source.

**Canonical Model:** Internal normalized representation used by the application independently of external API object shapes.
