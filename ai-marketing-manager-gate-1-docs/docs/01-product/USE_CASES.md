# Use Cases
**Document ID:** PROD-007 | **Version:** 1.0

## UC-001 Connect Meta
Actor: Workspace user  
Outcome: Authorized Meta assets become available to the workspace.

## UC-002 Query Campaign Performance
Actor: Authorized user  
Outcome: User receives accurate, appropriately scoped campaign metrics.

## UC-003 Diagnose Performance
Actor: Authorized user  
Outcome: System identifies supported metric changes and plausible contributing factors without presenting speculation as fact.

## UC-004 Mutate Campaign
Actor: Authorized user  
Outcome: A supported campaign mutation is safely executed or rejected.

## UC-005 Approve AI Action
Actor: Authorized approver  
Outcome: Pending action is approved/rejected and the decision is recorded.

## UC-006 Define Goal
Actor: Workspace user with permission  
Outcome: Goal is created with explicit objective, target, KPI, time window and applicable constraints.

## UC-007 Optimize
Actor: System  
Outcome: Candidate actions are evaluated and only permitted actions execute.

## UC-008 Generate Report
Actor: Authorized user  
Outcome: Report is generated from trusted synchronized data.

## UC-009 Emergency Stop
Actor: Authorized administrator  
Outcome: Eligible autonomous execution is halted.
