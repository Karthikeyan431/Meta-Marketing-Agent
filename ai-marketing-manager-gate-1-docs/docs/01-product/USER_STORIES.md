# User Stories
**Document ID:** PROD-006 | **Version:** 1.0

## Epic A — Workspace
US-A01: As a user, I can create a workspace.
US-A02: As an owner, I can invite members.
US-A03: As an owner, I can assign roles.
US-A04: As a member, I can only access authorized workspace data.

## Epic B — Meta Connection
US-B01: As a user, I can connect a Meta account using OAuth.
US-B02: As a user, I can select the advertising assets I want to manage.
US-B03: As a user, I can disconnect Meta.
US-B04: As a system, I can detect expired/invalid authorization.

## Epic C — Analytics
US-C01: As a user, I can ask for campaign performance in natural language.
US-C02: As a user, I can compare periods.
US-C03: As a user, I can identify underperforming campaigns.
US-C04: As a user, I can receive explanations for significant changes.

## Epic D — Execution
US-D01: As an authorized user, I can pause a campaign through chat.
US-D02: As an authorized user, I can resume a campaign.
US-D03: As an authorized user, I can update supported budgets.
US-D04: As a user, I can see what the AI plans to change before approval.
US-D05: As a user, I can see whether an action succeeded or failed.

## Epic E — Goals
US-E01: I can define a measurable marketing goal.
US-E02: I can view progress toward the goal.
US-E03: I can change or stop a goal.

## Epic F — Optimization
US-F01: I can configure autonomous optimization limits.
US-F02: The system can detect optimization opportunities.
US-F03: The system can execute only actions permitted by policy.
US-F04: I can review optimization history.

## Epic G — Reporting
US-G01: I can ask for a report in chat.
US-G02: I can compare reporting periods.
US-G03: I can receive goal-oriented summaries.

## Epic H — Governance
US-H01: I can configure approval thresholds.
US-H02: I can view audit logs.
US-H03: I can stop autonomous actions.
US-H04: The system prevents unauthorized or over-limit actions.
