# User Journeys
**Document ID:** PROD-005 | **Version:** 1.0

## Journey 1 — Connect Meta
Sign up → create workspace → connect Meta → authorize → discover assets → select ad account → initial sync → dashboard ready.

## Journey 2 — Understand Performance
Open chat → ask question → resolve context → retrieve metrics → calculate requested KPI → answer with freshness context and supporting entities.

## Journey 3 — Execute a Campaign Change
User request → entity resolution → authorization → parameter validation → policy evaluation → approval if required → execution → verification → audit → response.

## Journey 4 — Define a Goal
User states objective → AI extracts target/KPI/time/budget → validates ambiguity → creates goal → begins measurement.

## Journey 5 — Autonomous Optimization
Scheduled evaluation → data freshness check → detect opportunity → generate candidate action → evaluate policy/risk → approve/auto-approve → execute → verify → record → measure outcome.

## Journey 6 — Failure Recovery
Action fails → classify error → retry if safe → otherwise stop → record failure → communicate clearly → provide safe next step.

## Journey 7 — Emergency Stop
Authorized user triggers stop → disable autonomous execution → cancel eligible queued actions → preserve audit trail → confirm state.
