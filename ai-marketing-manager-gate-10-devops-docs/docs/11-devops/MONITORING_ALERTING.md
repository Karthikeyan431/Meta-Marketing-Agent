# Monitoring and Alerting
**Document ID:** DEVOPS-010 | Version 1.0

## Alert Classes
### Critical
- unauthorized access indicators
- cross-tenant security event
- unexpected spend/action anomaly
- database unavailable
- production-wide API failure

### High
- Meta integration failure
- queue backlog
- high action failure rate
- AI service degradation

### Informational
- sync delay
- approaching quota
- elevated latency

Alerts must be actionable and routed to an accountable owner.
