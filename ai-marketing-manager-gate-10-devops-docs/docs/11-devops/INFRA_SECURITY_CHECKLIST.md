# Production Infrastructure Security Checklist
**Document ID:** DEVOPS-018 | Version 1.0

- [ ] HTTPS/TLS configured
- [ ] WAF/edge controls configured
- [ ] database not publicly exposed
- [ ] secrets managed securely
- [ ] MFA enforced for privileged humans
- [ ] least-privilege service identities
- [ ] backups enabled
- [ ] restore tested
- [ ] logs centralized
- [ ] alerts configured
- [ ] dependency/image scanning enabled
- [ ] deployment credentials protected
- [ ] production access audited
- [ ] emergency action controls tested
