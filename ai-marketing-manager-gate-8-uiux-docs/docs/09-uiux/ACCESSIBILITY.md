# Accessibility Requirements
**Document ID:** UI-011 | Version 1.0

## Baseline
Target WCAG 2.2 AA.

## Requirements
- keyboard navigation
- visible focus
- semantic HTML
- accessible names
- sufficient contrast
- screen-reader compatible status updates
- error identification
- no color-only meaning
- reduced-motion support
- accessible data tables/charts with textual alternatives

## Chat
Streaming AI updates must be announced appropriately without overwhelming assistive technology.
