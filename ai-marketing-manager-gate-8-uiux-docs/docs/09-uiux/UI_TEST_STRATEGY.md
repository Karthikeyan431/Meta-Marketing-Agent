# UI/UX Test Strategy
**Document ID:** UI-015 | Version 1.0

## Automated
- component tests
- route tests
- accessibility tests
- API integration tests
- keyboard interaction tests
- responsive layout tests
- critical workflow E2E

## Critical E2E
1. Login/session.
2. Connect Meta.
3. Select account.
4. Search campaign using Ctrl/Cmd+K.
5. Ask AI for campaign performance.
6. Preview budget change.
7. Approve action.
8. Verify action result.
9. View audit/history.
10. Generate report.

## Negative E2E
- unauthorized account
- ambiguous search
- expired connection
- failed Meta action
- stale data
- rejected approval
- duplicate action
- cross-workspace access
