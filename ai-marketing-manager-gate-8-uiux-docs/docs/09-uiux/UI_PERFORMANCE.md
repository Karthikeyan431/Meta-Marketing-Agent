# UI Performance Requirements
**Document ID:** UI-016 | Version 1.0

## Targets
Define measurable budgets before implementation.

Initial goals:
- fast first meaningful render
- route-level code splitting
- virtualize large campaign/ad tables
- debounce global search
- paginate large datasets
- stream AI responses where beneficial
- avoid unnecessary re-rendering

## UX Rule
Performance optimization must not weaken authorization, correctness or action-state truth.
