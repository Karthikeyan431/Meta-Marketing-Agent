# Campaign Management UX
**Document ID:** UI-004 | Version 1.0

## Campaign Table
Columns should be configurable, with a sensible default:
- Campaign
- Status
- Objective
- Spend
- Results
- Cost per Result
- CTR
- CPM
- Date range
- Last synced

## Bulk Actions
Bulk actions require:
- selection summary
- affected count
- policy check
- preview
- approval when required
- progress
- per-item outcome

## Campaign Detail

```text
Campaign Header
Status | Objective | Spend | Results | Cost/Result

[Overview] [Ad Sets] [Ads] [Insights] [Activity]

Performance charts
AI analysis
Recent changes
Recommended actions
```

The UI must distinguish source metrics from AI interpretation.
