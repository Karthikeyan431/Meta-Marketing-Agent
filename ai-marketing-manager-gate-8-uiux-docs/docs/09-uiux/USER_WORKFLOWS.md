# Core User Workflows
**Document ID:** UI-013 | Version 1.0

## Workflow 1 — Connect Meta
Login → Connections → Connect Meta → Authorize → Select Ad Account → Sync → Dashboard.

## Workflow 2 — Investigate Performance
Chat → natural-language question → AI retrieves metrics → evidence → explanation → linked campaign/account.

## Workflow 3 — Execute Change
Chat → entity resolution → proposed action → policy → approval → execution → verification → audit → chat confirmation.

## Workflow 4 — Search
Ctrl/Cmd+K → query → categorized results → correct destination → resource detail.

## Workflow 5 — Generate Report
Chat or Reports → configure range/metrics → generate → inspect freshness → share/export.

## Workflow 6 — Failure
Request → failure → truthful status → remediation → retry when safe.
