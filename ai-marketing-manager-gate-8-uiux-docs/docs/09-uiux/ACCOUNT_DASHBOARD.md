# Ad Account Dashboard UX
**Document ID:** UI-005 | Version 1.0

## Overview
Display:
- spend
- results
- cost per result
- ROAS where applicable
- impressions
- reach
- CTR
- CPM
- trend comparisons

## Freshness
Every dashboard that depends on synchronized Meta data should expose a last-updated/freshness indicator.

## AI Summary
Example:

```text
AI Summary
Spend is up 18% week-over-week.
Lead volume is up 7%.
CPL increased 10%, primarily from Campaign X.
```

The AI summary must link claims to available source data.
