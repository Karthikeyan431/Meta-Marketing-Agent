# Reporting UX
**Document ID:** UI-007 | Version 1.0

## Report Builder
Allow:
- account/campaign selection
- date range
- metrics
- breakdowns
- comparison period
- filters
- delivery format

## AI Reporting
Users can ask:
“Give me a weekly Meta performance report and explain what changed.”

The system should return:
- executive summary
- KPI table
- trend analysis
- notable changes
- campaign highlights
- recommended actions
- data freshness

## Trust
Reports must distinguish:
- source facts
- calculated metrics
- AI interpretation
- recommendations
