# Meta App / Production Readiness
**Document ID:** META-010 | Version 1.0

## Before Production
- Meta app configured
- valid OAuth redirect configuration
- required permissions/capabilities identified
- privacy/data-use documentation prepared
- production domains configured
- webhook endpoint secured
- app review requirements checked for requested capabilities
- test users/accounts established
- failure/revocation handling tested
- monitoring enabled

## Important
Meta requirements and permissions can change. Before implementation freeze and production submission, re-check the current Meta developer documentation rather than treating this document as a permanent permission list.

## Operational Readiness
- support owner assigned
- token/reconnection flow tested
- incident runbook prepared
- API version upgrade process documented
